# Estándares de Contribución

¡Gracias por tu interés en mejorar este clon de Airbnb! Para mantener la calidad del proyecto, sigue estas pautas:

## Cómo Contribuir

1. **Fork** el proyecto.
2. Crea una **Rama de Función** (`git checkout -b feature/NuevaFuncionalidad`).
3. Haz **Commit** de tus cambios (`git commit -m 'Añadir NuevaFuncionalidad'`).
4. **Push** a la rama (`git push origin feature/NuevaFuncionalidad`).
5. Abre un **Pull Request**.

## Guía de Estilos

- Usa **nombres descriptivos** para variables y funciones en inglés o español (pero sé consistente).
- Los componentes deben estar en la carpeta `src/components`.
- Mantén el diseño fiel a la estética de Airbnb (minimalista, bordes redondeados, tipografía limpia).
